# book-tracker

Гылыков Эрдэм

## Описание
**book-tracker** - программа для отслеживания прочитанных книг. Позволяет записывать автора, оценку книги и дату прочтения.

## Запуск программы

### 1. Клонирование
В Git Bash, запустите команду: `git clone "https://github.com/VisDeveloper/4-module-certification.git"`
> Допускается прямое скачивание со страницы GitHub

### 2. Запуск
Выйдите из Git Bash и запустите терминал в папке "4-module-certification", впишите в зависимости от операционной системы:

#### Windows:
`python main.py`

#### Linux:
`python3 main.py`

> Допускается запуск программы в сторонних программах, не рекомендуется запускать в Git Bash, так-как кириллица превращается в кашу

### 3. Использование
В меню предоставляется 6 опций:
1. Добавить книгу
> Добавляет и сохраняет книгу в прочитанную библиотеку
2. Показать все книги
> Показывает все книги и записанные данные
3. Средняя оценка
> Средняя арифметическая оценка всех книг
4. Статистика по авторам
> Показывает количество прочитанных книг каждого автора
5. Удалить книгу
> Удаляет книгу по индексу из данных
6. Выход
> Безопасный выход из программы
